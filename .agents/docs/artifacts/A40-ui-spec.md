# A40 - UI Spec

## Layout
- **Desktop**: Split view. Left 66% Viz, Right 33% Story.
- **Mobile**: Column view. Viz top, Story bottom.

## Components
- **ForceGraph**: Interactive canvas. Click to jump. Hover for tooltip.
- **StoryPanel**: Auto-scrolling text stream. Fragments colored by type.
- **Controls**:
  - Play/Pause
  - Reset
  - Speed Slider (500ms - 5000ms)

## Styling
- **Font**: Monospace / System.
- **Theme**: Minimalist Dark Mode.
